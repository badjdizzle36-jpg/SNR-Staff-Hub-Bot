INSTALL
1. Extract SNR_City_Run_Marketplace_Final_Centered.zip.
2. Copy every supplied Python file, city-run-board-v4.png and the complete
   city-run-stickers folder into the repository folder containing bot.py.
3. Choose Replace when Windows asks about matching files. Do not remove your
   database, .env file, Railway variables or unrelated repository files.
4. In GitHub Desktop, commit with:
   Finalise centred City Run Marketplace
5. Click Push origin and wait for Railway to finish deploying.
6. Open Sticker Exchange. The controller is now marked no-store, but perform
   one Ctrl + F5 refresh after the first deployment to clear the older page.
